Cliente de transmissão de tela feito **só para o servidor do Discord BDK**. O repositório é público apenas para as atualizações automáticas funcionarem; o app não serve para outro uso.

## Instalar

**Linux**

```bash
flatpak install --user https://codestage-pro.github.io/project-luce/luce.flatpakref
```

**Windows:** baixe o `Luce-Setup.exe` na [última versão](https://github.com/Codestage-pro/project-luce/releases/latest).

Na primeira abertura, digite o seu **nome** e a **senha do grupo**. As atualizações são avisadas dentro do app e instaladas com um clique.

## O que tem

- Transmitir a tela inteira ou uma janela (no Windows), com áudio do sistema ou de um app
- Assistir várias transmissões ao mesmo tempo, com volume e mute por pessoa
- Codificação na GPU (NVIDIA, AMD e Intel); CPU só se não houver placa compatível
- Qualidade, fps e bitrate nas configurações, estatísticas ao vivo e lista de quem está assistindo
- Fica na bandeja do sistema ao fechar (dá para desligar nas configurações)
